Computer Science Terminology

20 Web Development Terminologies

HTML
HyperText Markup Language used to structure web pages.
CSS
Cascading Style Sheets used to style websites.
JavaScript
A programming language used to make websites interactive.
Frontend
The visible part of a website users interact with.
Backend
The server-side part that handles data and logic.
Responsive Design
A design approach that makes websites work on all devices.
API
Application Programming Interface used for communication between systems.
Browser
Software used to access websites like Chrome or Firefox.
Domain
The address of a website on the internet.
Hosting
A service that stores website files online.
SEO
Search Engine Optimization improves website visibility on search engines.
Git
A version control system used to track code changes.
GitHub
A platform for storing and sharing code repositories.
Semantic HTML
HTML elements that clearly describe their meaning.
Flexbox
A CSS layout system for arranging items in rows or columns.
Grid
A CSS layout system for creating two-dimensional layouts.
Viewport
The visible area of a webpage on a device screen.
Form
An HTML element used to collect user information.
Database
A structured collection of data stored electronically.
Framework
A pre-built structure that helps developers build applications faster.
